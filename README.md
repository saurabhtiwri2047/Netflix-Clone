# 🎬 Netflix Clone

A responsive **Netflix Clone** built using **HTML, CSS, and JavaScript**. This project recreates the modern look and feel of Netflix's landing page and demonstrates frontend development, responsive design, and interactive UI skills.

## 🚀 Live Demo

🌐 **[View Live Website](https://netflix-clone-2026-cppc.onrender.com/)**

## 📸 Features

* 🎬 Netflix-inspired landing page
* 🔐 Sign In UI
* 📧 Email registration / Get Started section
* 📺 Watch on TV section
* 📱 Responsive design
* 💻 Multiple-device support
* 👨‍👩‍👧 Kids profile section
* ❓ Frequently Asked Questions (FAQ)
* 🎨 Modern Netflix-style UI
* ⚡ Interactive JavaScript elements
* 🌐 Deployed on Render

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Interactivity and dynamic behavior

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Netflix-Clone.git
```

### 2. Open the project

```bash
cd Netflix-Clone
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server** for a better development experience.
